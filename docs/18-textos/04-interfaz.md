Avisos de cierre (banda arriba):
- Temporal: «Este local está cerrado temporalmente. Te avisamos aquí cuando vuelva a abrir.» / «This place is temporarily closed. We’ll update this page when it reopens.» / «Cet établissement est temporairement fermé. Cette page sera mise à jour à sa réouverture.»

- Bloque: «Alternativas cercanas» / «Nearby alternatives» / «Alternatives proches».

## 9. Correos (texto sencillo, sin seguimiento)

**Código de acceso**
- Asunto: «Tu código de Tablemaroc: {código}» / «Your Tablemaroc code: {código}» / «Votre code Tablemaroc : {código}»
- Cuerpo es: «Hola: tu código para entrar en Tablemaroc es {código}. Caduca en 10 minutos. Si no lo has pedido tú, ignora este email.»
- en: «Hello, your code to sign in to Tablemaroc is {código}. It expires in 10 minutes. If you didn’t ask for it, ignore this email.»
- fr: «Bonjour, votre code pour vous connecter à Tablemaroc est {código}. Il expire dans 10 minutes. Si vous ne l’avez pas demandé, ignorez cet email.»

**Reserva recibida (pendiente)**
- Asunto: «Hemos recibido tu solicitud de reserva en {local}» / «We’ve received your booking request at {local}» / «Nous avons reçu votre demande de réservation chez {local}»
- es: «{local} · {día} a las {hora} · {n} personas. El local la confirmará y te escribiremos. Puedes cancelarla cuando quieras en Mi cuenta → Reservas.»

**Reserva confirmada**
- Asunto: «Reserva confirmada en {local}» / «Booking confirmed at {local}» / «Réservation confirmée chez {local}»
- es: «Te esperan el {día} a las {hora} ({n} personas). Dirección: {dirección}. Cómo llegar: {enlace}. ¿No puedes ir? Cancélala en Mi cuenta → Reservas.»

**Reserva no disponible**
- Asunto: «{local} no puede atender tu reserva» / «{local} can’t take your booking» / «{local} ne peut pas honorer votre réservation»
- es: «Lo sentimos: {local} no tiene sitio el {día} a las {hora}. Mira otros locales cerca: {enlace}.»

**Reseña publicada / no publicada**
- es: «Tu reseña de {local} ya está publicada. ¡Gracias por ayudar a otros viajeros!» · «Tu reseña de {local} no se ha publicado: {motivo}. Puedes editarla en Mi cuenta → Reseñas.»
- en: «Your review of {local} is now live. Thanks for helping other travellers!» · «Your review of {local} wasn’t published: {motivo}. You can edit it in My account → Reviews.»
- fr: «Votre avis sur {local} est publié. Merci d’aider les autres voyageurs !» · «Votre avis sur {local} n’a pas été publié : {motivo}. Vous pouvez le modifier dans Mon compte → Avis.»
